Research Highlights

My first-author research by theme — the contribution and its architecture. Full citations with venues and DOIs are in the publication list below.

Epidemic & Health Time-Series Forecasting

Multimodal, interpretable deep-learning models for influenza and COVID-19 surveillance data.

  • Forecasting model

    Recurrent Self-Attention Forecasting (RESEAT)

    Per-region LSTMs coupled with recurrently connected self-attention forecast many regions jointly and expose how inter-regional relationships shift over time, outperforming SOTA on influenza and COVID-19 data.

    • Self-Attention
    • LSTM
    • Multivariate Time Series
    • Interpretability

  • Input selection

    Two-Stage Data Selection

    Automatically selects which of 168 countries' WHO FluNet surveillance data help long-term (26-week) influenza prediction, cutting RMSE by up to ~47% across 6 ML models and 3 target countries.

    • Feature Selection
    • Long-Term Forecasting
    • Machine Learning

Meta-Learning for Data-Scarce Prediction

Model-agnostic meta-learning (MAML) pre-trains shared knowledge across tasks for fast few-shot adaptation. I applied it to two distinct problems:

  • Influenza forecasting

    Region-Adaptive Meta-Learning (MARAPAS)

    Meta-learns a region-adaptive initialization so an influenza forecaster adapts to a new region from only a few samples, beating conventional training under data scarcity.

    • MAML
    • Few-Shot Learning
    • Influenza Forecasting

  • Multivariate sensor anomaly detection

    Meta-Learned VAE (MAVAE)

    Meta-learns a VAE on normal multivariate sensor data across facilities, then adapts to a new facility from few normal samples to flag anomalies — ~45% average F1/AUC gain over SOTA on the SKAB benchmark.

    • MAML
    • VAE
    • Anomaly Detection
    • Sensor Time Series

Generative Modeling & Data Augmentation

Synthesizing training data where real records are scarce.

  • Data augmentation

    Two-Stage GAN Augmentation (CTGAN)

    CTGAN synthesizes virtual input variables and a regression model produces the matching outputs, preserving input–output correlations to consistently boost short-term load forecasting under data scarcity.

    • CTGAN
    • Data Augmentation
    • Load Forecasting

Projects

  • Explainable ILI Forecasting with LLMs

    First-author research project: combines ILI time series with CDC FluView / Japan IDWR surveillance reports, using GPT-generated explanation labels to LoRA fine-tune LLaMA-3.1-70B (LLaMA-Factory, DeepSpeed ZeRO-3) so the model produces predictions together with the reasoning behind them. Includes an LLM-judge evaluation of explanation quality and classic TSF baselines (DLinear, PatchTST, etc.).

    • LLaMA-3.1-70B
    • LoRA
    • LLaMA-Factory
    • DeepSpeed
    • vLLM

  • Hierarchical AI Agent Framework

    A hierarchical multi-agent chatbot framework built for an Incheon International Airport chatbot project: a main agent recursively delegates tasks to sub-agents (browser, PDF, vector-DB), and every action is emitted as executable Python code (CodeAct/ReAct paradigm). Native functions, MCP server tools, and sub-agents are all exposed to the LLM as uniform callable tools.

    • Multi-Agent
    • CodeAct/ReAct
    • MCP
    • LangChain
    • Python
